# MORTIS CLOUDS — Android (.apk)

TWA signée qui charge https://mortisia.nekuzaky.com/m/ — l'app suit donc
automatiquement les mises à jour du serveur, pas besoin de réinstaller.

## Installer
1. Sur ton téléphone, télécharge : **[MORTIS-CLOUDS.apk](https://github.com/Nekuzaky/MortisClouds-releases/raw/main/apk/MORTIS-CLOUDS.apk)**
2. Ouvre le fichier → autorise « Installer depuis cette source »
3. L'app MORTIS apparaît (plein écran)

Package : `com.nekuzaky.mortisia.twa`
